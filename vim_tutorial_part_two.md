Someone I know recently pointed out some additional resources on vim:

1. https://vim.rtorr.com/
2. https://openvim.com/

Both resources are really useful. The first is a "cheat sheet", which teaches you a lot about vim. The second is an interactive tutorial.

It's interesting that, in the interactive tutorial, they use a two-mode division for explaining vim modes. The interactive tutorial says that vim has two basic modes, insert mode and normal mode. This is a great way of thinking about vim's modes.

I also found this tutorial, before today, in which the authors say that vim has two modes: insert mode and command mode.

3. https://web.stanford.edu/class/cs107/resources/vim

So you can see there are many ways of describing vim's modes.

Some people say there are two basic modes. Some people say there are three basic modes. Some people call these modes insert mode and normal mode. Some people call these modes insert mode and command mode. Some people say there are three basic modes: insert mode, normal mode, and command mode.

The way you talk about it might be a matter of preference.

But sometimes it helps to know what language is commonly used to describe something.

The interactive tutorial (resource #2) shows that we can use the escape key and the "i" key to switch between normal mode and insert mode. I sometimes use the escape key to switch into normal mode. Other times, I use the key sequence control+c.

I often use the key sequence control+c to switch into normal mode, because I find it easier. But the escape key works, too.

All three websites are really useful resources on the vim text editor.
