Example usage
=============

AddSubtract.java
----------------

Example 1:

    # cd to the part1_addsubtract directory
    % cd ~/Github/cryptography_tutorial/part1_addsubtract

    # Compile the Java source code into bytecode
    % javac AddSubtract.java ../lib/argparse/*.java

    # Set the classpath
    % export CLASSPATH=.:../lib

    # Encrypt a message; set the key to 100
    % java AddSubtract "hello world today is wednesday" -k 100 -e

    # Encrypt a message; set the key to 100; write to cipher.txt
    % java AddSubtract "hello world today is wednesday" -k 100 -e -o cipher.txt

    # Inspect cipher.txt
    % cat cipher.txt

    # Decrypt cipher.txt
    % java AddSubtract -i cipher.txt -k 100 -d
    hello world today is wednesday

Example 2 (base64 encoding):

    # cd to the part1_addsubtract directory
    % cd ~/Github/cryptography_tutorial/part1_addsubtract

    # Compile the Java source code into bytecode
    % javac AddSubtract.java ../lib/argparse/*.java

    # Set the classpath
    % export CLASSPATH=.:../lib

    # Encrypt a message; set the key to 100
    % java AddSubtract "hello world today is wednesday" -k 100 -e -b64

    # Encrypt a message; set the key to 100; write to cipher.txt
    % java AddSubtract "hello world today is wednesday" -k 100 -e -o cipher.txt

    # Inspect cipher.txt
    % cat cipher.txt
    w4zDicOQw5DDk8KEw5vDk8OWw5DDiMKEw5jDk8OIw4XDncKEw43Dl8KEw5vDicOIw5LDicOXw4jDhcOd

    # Decrypt cipher.txt

asencrypt.py and asdecrypt.py
-----------------------------

Example 1:

    # cd to the part1_addsubtract directory
    % cd ~/Github/cryptography_tutorial/part1_addsubtract

    # Encrypt a message with a key of 10,000 (1e5 = 1*10^5)
    % python asencrypt.py "hello world today is wednesday" -k 1e5
    8JiciPCYnIXwmJyM8JicjPCYnI/wmJuA8Jicl/CYnI/wmJyS8JicjPCYnITwmJuA8JiclPCYnI/wmJyE8JicgfCYnJnwmJuA8JicifCYnJPwmJuA8Jicl/CYnIXwmJyE8JicjvCYnIXwmJyT8JichPCYnIHwmJyZ

    # Encrypt a message with a key of 10,000 and write to cipher.txt
    % python asencrypt.py "hello world today is wednesday" -k 1e5 -o cipher.txt

    # Inspect cipher.txt
    % cat cipher.txt
    8JiciPCYnIXwmJyM8JicjPCYnI/wmJuA8Jicl/CYnI/wmJyS8JicjPCYnITwmJuA8JiclPCYnI/wmJyE8JicgfCYnJnwmJuA8JicifCYnJPwmJuA8Jicl/CYnIXwmJyE8JicjvCYnIXwmJyT8JichPCYnIHwmJyZ

    # Decrypt cipher.txt
    % python asdecrypt.py -i cipher.txt -k 1e5
    hello world today is wednesday

Notes:
------
* In AddSubtract.java, base64 encoding is an option controlled by the -b64 flag
* In addsubtract.py, asencrypt.py, and asdecrypt.py, base64 encoding is always on
