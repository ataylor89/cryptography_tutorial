Example usage
=============

Rot88.java
----------

Example 1:

    # cd to the part3_rot88 directory
    % cd ~/Github/cryptography_tutorial/part3_rot88

    # Compile the Java source code into bytecode
    % javac Rot88.java ../lib/argparse/*.java

    # Set the classpath
    % export CLASSPATH=.:../lib

    # Encrypt a message using the rot88 algorithm
    % java Rot88 "hello world today is thursday" -e

    # Encrypt a message using the rot88 algorithm, and write to cipher.txt
    % java Rot88 "hello world today is thursday" -e -o cipher.txt

    # Inspect cipher.txt
    % cat cipher.txt

    # Decrypt cipher.txt
    % java Rot88 -i cipher.txt -d
    hello world today is thursday
