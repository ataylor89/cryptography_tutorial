Example usage
=============

Introduction
------------

The files keygen.py, encrypt.py, and decrypt.py are used by the user.
The other files are helper files.

Usage of keygen.py, encrypt.py, and decrypt.py
----------------------------------------------

Example 1:

    # cd to the part6_rsa directory
    % cd ~/Github/cryptography_tutorial/part6_rsa

    # Bring up the help menu
    % python keygen.py -h

      -v, --verbose

Notes
-----
* p and q are two large prime numbers that satisfy the following conditions:
*   p and q are randomly chosen and distinct
*   p and q are somewhere between a lower bound and an upper bound
* n is defined as n = p * q
*   n is often called the modulus
*   n is a semiprime, the product of two prime numbers
* d is a large, random integer that is relatively prime to (p-1)(q-1)
*   Note that ϕ(n) = (p-1)(q-1), where ϕ is Euler's totient function
*   Two integers are relatively prime if their greatest common divisor is 1
*   d is often called the decryption exponent
* e is the multiplicative inverse of d modulo (p-1)(q-1)
*   e is often called the encryption exponent
* The encryption function E(m) is defined as E(m) = m^e (mod n)
*   m is the code point of a Unicode character (e.g. 97 is the code point for 'a')
* The decryption function D(c) is defined as D(c) = c^d (mod n)
*   c is the output of the encryption function
*   D(c) = m and E(m) = c
* We can use Euler's totient theorem to prove that D(E(M)) = M and E(D(C)) = C
* This means that E(M) and D(C) are inverses and we can use them for cryptography
* A public key is a list of (n, e) tuples
*   We share our public key with a trusted party
*   But we also keep our public key as secret as possible
*   The trusted party shares their public key with us
*   This is called an RSA handshake or a public key exchange
*   The trusted party uses our public key to encrypt the messages they send us
*   We use the trusted party's public key to encrypt messages we send them
* A private key is a list of (n, d) tuples
*   We do not share our private key with anyone
*   We use our private key to decrypt messages that we receive from a trusted party
*   The trusted party uses their private key to decrypt messages that they receive
* Example:
*   Alex and Bob both have their own public key and private key
*   Alex shares his public key with Bob
*   Bob shares his public key with Alex
*   Alex uses Bob's public key to encrypt a message, and sends the message to Bob
*   Bob uses his private key to decrypt the message he received from Alex
*   Bob uses Alex's public key to encrypt a message, and sends the message to Alex
*   Alex uses his private key to decrypt the message he received from Bob
